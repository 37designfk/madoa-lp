# 広告クリエイティブ素材

Meta広告・Google広告に入稿するバナー素材の置き場。**LPからは参照していない。**

## public/ に置かない理由

以前は `public/images/ads/` に置いていたが、Astro は `public/` 配下をそのまま `dist/` へコピーするため、
LPから一度も参照していない素材 114件・72MB が GitHub Pages と本番（lp.madoa.co.jp）の両方に
毎回アップロードされていた。入稿前の没案も含めて誰でも取得できる状態だったため、
2026-07-26 に `public/` の外へ移動した。

配信対象から外れただけで、リポジトリ内には残っている。Meta へは image_hash で入稿済みのため、
パス変更による影響はない。
