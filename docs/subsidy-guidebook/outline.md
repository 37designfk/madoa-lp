# 補助金ガイドブック2026年版 構成案・インタビュー項目

LINE登録特典として無料配布する電子書籍（Kindle電子書籍として有料販売も並行検討）。
大井葬儀の電子書籍事例を雛形に、AI生成台本＋菊池さんインタビューで肉付けする。

## 目的・KPI

- **目的**:
  1. LINE登録のフック化（補助金ガイドブック2026年版プレゼント）
  2. 訪問・現調時の名刺代わり（300〜500円の冊子化、Amazon Kindleでの実本化）
  3. 「窓ガラス屋＝窓・網戸・玄関ドアまで対応できる」という認知拡大
- **KPI**:
  - LINE登録CVR: LP訪問の3% → 7%
  - 冊子配布: 月50冊（現場・営業同行・反響）
  - Amazon Kindle販売: 月10部（300〜500円帯）

## ターゲット読者

- 神戸市西区＋一円の持ち家 35-65歳の主婦層・夫婦層
- 「窓が古い」「結露がひどい」「電気代が上がって困っている」と感じているが、補助金制度がよくわからない人
- リフォーム会社に相見積もりを取りたいが、何を聞けばいいかわからない人

## 章立て（仮）

### 第1章 はじめに — 窓を変えるだけで、家はここまで変わる

- 窓は家の中で最も熱が逃げる場所（壁の約6倍）
- 結露・底冷え・電気代の元凶は窓ガラスにある
- 補助金で実質半額以下、最大100万円まで戻る制度がある

### 第2章 2026年版「先進的窓リノベ事業」のすべて

- 制度の正式名・実施主体・予算規模
- 対象工事（ガラス交換 / 内窓設置 / 外窓交換 / ドア交換）
- 補助上限額・補助率の一覧表
- 申請期限・予算消化のスケジュール感（早い者勝ち）
- 他補助金との併用可否（子育てエコホーム、長期優良住宅化、自治体独自）

### 第3章 自分の家はいくらもらえる？タイプ別シミュレーション

- 一戸建て・小規模（窓2か所）
- 一戸建て・中規模（窓5か所、リビング+寝室+子供部屋）
- 一戸建て・全面（窓10か所以上）
- マンション（管理組合の同意プロセス含む）
- 各タイプで「通常価格 → 補助金額 → 実質負担」を表で提示

### 第4章 失敗しないリフォーム会社の選び方

- 補助金の知識があるか（登録事業者か）
- 現調から見積もりまでのスピード
- 追加費用の発生条件を最初に明示するか
- 施工後のアフター（結露・隙間風が出た時の対応）
- 「相見積もりを取って当たり前」と言えるか

### 第5章 窓ガラス屋の本当の仕事 — MADOA 50年で見てきたこと

- ガラス1枚交換から、家全体の断熱リノベまで
- 緊急対応（夜中の窓割れ）から、計画リフォームまで
- 網戸・玄関ドア・サッシまわりも全部できる
- 神戸市西区を50年見続けてきて気づいたこと

### 第7章 まずはLINEで30秒、写真1枚から

- LINE登録の流れ
- 写真の撮り方（窓全体・サッシ部分・窓枠の幅）
- 概算見積もりが返ってくるまでの時間
- 現調訪問の流れ

### 巻末付録

- 補助金制度の比較表（先進的窓リノベ / 子育てエコホーム / 自治体独自）
- 神戸市・明石市・芦屋市の独自補助金一覧（2026年最新版）
- MADOA 施工事例ギャラリー（カラー写真10枚）
- お客様の声42件抜粋（LIXIL窓本舗より）

## 菊池さんインタビュー項目（90〜120分想定）

### A. 創業・歴史（10分）

- 株式会社三喜の創業年・きっかけ
- 創業当時の神戸の窓ガラス事情
- 50年で一番変わったことは何か
- 二代目として継いだ経緯・覚悟

### B. 補助金制度との関わり（20分）

- 先進的窓リノベ事業の制度を知ったタイミング
- 国の制度に振り回された経験（出たり消えたり）
- 補助金制度をお客様に説明する時の工夫
- 「補助金が出る」と聞いた時のお客様の典型反応
- 補助金を使った人と使わなかった人の差

### C. 印象に残った現場（25分）

- 50年で一番嬉しかった現場
- 一番大変だった現場（夜中の窓割れ・大雪・地震後対応）
- 「ガラス屋でこんなことまで」と言われた仕事
- 紹介で繋がっていった家族の話
- お客様から手紙・写真が届いたエピソード

### D. 窓ガラス屋の仕事観（20分）

- 「窓ガラス屋」と「リフォーム会社」の違い
- 一枚のガラスにこめる責任
- 神戸市西区という地域でやり続ける理由
- 職人さんとの関係・育成
- 嘘をつかない見積もり、追加費用を出さない見積もり

### E. これからのMADOA（15分）

- 三代目・若手職人への思い
- AIや新しい技術との向き合い方（現場アプリ等）
- 「窓だけじゃない家まわり」をどこまで広げるか
- 神戸の窓を、これから10年でどうしたいか

### F. 読者へのメッセージ（10分）

- 補助金で迷っている人へ
- 相見積もりを取ろうか迷っている人へ
- 家の寒さで諦めている人へ
- ガラス屋を「呼んでいいのかわからない」と思っている人へ
