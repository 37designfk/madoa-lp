# 関係者アクセスを計測から外す手順（配布用）

計測データに我々のアクセスが混ざると、広告の効果が正しく測れない。
関係者は各自の端末で一度だけ下記を開いてほしい。

## 配布状況

| 相手 | 状況 |
|---|---|
| 菊池様 | **2026-08-08 LINEで送付済み**。踏んでいただけたかは未確認 |
| 羽田野さん | 送付不要（古田判断・2026-08-08） |
| 古田 | Chrome に印を設定済み（2026-08-08） |

菊池様が実際に踏まれたかは、GA4で `tt=internal` が付いたアクセスが出るかで確認できる。
数日たっても関係者らしきアクセスが減らない場合は、
**LINE内蔵ブラウザで開かれた可能性**（下記「注意」参照）を疑って踏み直しを依頼する。

## やること

普段LPを見るブラウザで、このURLを一度だけ開く。

```
https://lp.madoa.co.jp/?internal=1
```

これだけ。開いた瞬間にそのブラウザに印が付き、以後は普通に
`lp.madoa.co.jp` を見るだけで計測対象から外れ続ける。

## 端末ごとに必要

印はブラウザごとに付く。**スマホとパソコンの両方**で開く。
仕事用と個人用でブラウザを使い分けているなら、それぞれで開く。

## 解除するとき

```
https://lp.madoa.co.jp/?internal=0
```

## 注意

<important>
**LINEやメールのリンクをそのままタップしても効かない。**

LINEでリンクをタップすると「LINE内蔵ブラウザ」で開く。印はそのブラウザにしか付かないため、
普段LPを見る Safari / Chrome には反映されない。

必ず **リンクを長押しして「Safariで開く」** を選ぶか、
**URLをコピーして普段使うブラウザに貼り付けて**開いてもらう。
案内文にはこの一手間を必ず書くこと。
</important>

- シークレットウィンドウ（プライベートモード）では効かない
- ブラウザの閲覧データを消すと印も消えるので、開き直しが要る
  - **ブックマークを `?internal=1` 付きで登録しておくと、消えても踏み直しが自動になる**
- 印が付いた端末は本当に一切記録されない。動作確認のアクセスもデータに残らない
