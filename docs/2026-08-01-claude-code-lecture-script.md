1. **エラーをそのまま Claude に貼って聞く**
   7/13 にお見せした形。「分からないことはとにかくこいつに聞く」。これ自体がデモになるので、詰まりを教材に変えられる

2. **古田の画面に切り替えて、完成状態のデモを見る**
   菊池様の環境構築は後日 LINE でやり取りする形に落とす。**講座の中身（CLAUDE.md の考え方と業務デモ）は古田の画面でも100%伝わる**ので、成果ゼロにはならない

3. **デスクトップアプリ版に切り替える**（手順書 8章）
   CLI がどうしても動かない場合。https://claude.com/download からインストーラーを落として実行する形なので、PATH の問題は起きない。ただし **Windows でローカルフォルダを扱うには Git が必要**な点に注意。この切り替えは事前に古田が試していないので、**その場の最終手段**とする
