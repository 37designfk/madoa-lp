# マネーフォワード クラウド請求書 API / MCP 連携可否（2026-07-25 調査）

7/13打ち合わせの宿題「マネーフォワード請求書機能のMCP/API連携可否を調査」の結果。

## 結論

**請求書はMCPサーバー未提供。REST APIのみ。** 会計と同じようにAnti-Gravityから自然文で叩くには、ひと手間（自作MCPラッパー or APIスクリプト）が要る。

## 根拠

マネーフォワード クラウド開発者サイト（https://developers.biz.moneyforward.com/ ）が公開している一覧:

| プロダクト | API | MCP |
|---|---|---|
| クラウド会計 | あり | **あり**（7/13に連携成功したのはこれ） |
| クラウド請求書 | あり（v3） | なし |
| クラウド経費 | あり | なし |
| クラウド債務支払 | あり | なし |
| クラウドインボイス［受領］ | あり | なし |

MCPが出ているのはクラウド会計のみ。菊池さんのPCに設定した `https://beta.mcp.developers.biz.moneyforward.com/mcp/ca/v3` の `ca` は cloud accounting を指し、請求書は含まれない。

## クラウド請求書APIの仕様（要点）

- ドキュメント: https://biz.moneyforward.com/support/invoice/guide/api-guide/a03.html
- リファレンス: https://invoice.moneyforward.com/docs/api/v3/index.html
- 認可: OAuth 2.0（会計APIと同じ認可サーバー）
- スコープ: `mfc/invoice/data.read`（参照）／ `mfc/invoice/data.write`（作成・更新・削除）
- 主なエンドポイント: `/api/v3/billings`（請求書）、`/api/v3/quotes`（見積書）、`/api/v3/invoice_template_billings`（テンプレート請求）
- できること: 請求書の作成・取得・更新、売上仕訳・消込仕訳の参照
- 料金: クラウド請求書を利用中なら **APIの追加料金なし**
- レート制限: 作成系は 1秒3回まで（超過で 429）

### プランによる作成上限（重要）

| 法人プラン | 各帳票の作成リクエスト上限 |
|---|---|
| 無償利用状態 | 100 |
| ひとり法人 | 100 |
| スモールビジネス | 100 |
| ビジネス | 上限なし |

三喜さんが現在どのプランかによって、API経由の請求書自動作成の実用性が変わる。**月あたり100件で足りるかを菊池さんに確認**するのが先。

## 三喜さんで実現するなら

1. **参照だけで良い場合** — 請求書一覧・入金状況の照会くらいなら、APIスクリプトを1本書いてAnti-Gravityから呼ぶ形が最短
2. **請求書の自動作成まで** — 自作のMCPラッパーを立てれば会計と同じ体験にできる。工数は数日規模
3. **待つ** — 会計にMCPが出たのが2026年3月。請求書にも遅れて提供される可能性はある。急がないなら様子見も合理的
