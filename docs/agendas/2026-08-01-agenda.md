## 調査の経緯（2026-08-01 未明・Graph API / GA4 Data API 実測）

診断が2回変わった。最終結論は3つ目。

1. 第1仮説「配信が若年層に流れた」— 年齢別CTRの劣化（35-44が3.79%→1.10%）は事実だが**主因ではない**
2. 第2仮説「オーガニックがCV源で、それが枯れた」— オーガニックの正体が関係者だったので**成立しない**
3. **最終結論: 広告経由のモバイルが最初からLPを読んでいない。加えて計測値に関係者アクセスとボットが混入していた**
