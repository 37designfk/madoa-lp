## 1. 数字の読み解き

### 直帰90%・滞在10秒が意味すること

滞在10秒は「読んで、興味がなかった」ではありません。**開いて、見て、閉じた**という時間です。人は10秒では本文を読めません。

つまり離脱しているのは**ファーストビューだけ**です。本文の内容・料金・実績は、そもそも見られていません。

ここが重要で、**母集団を絞っても改善しません。** 年齢を絞ってもエリアを絞っても、「開いた瞬間に閉じる」構造は変わらないからです。前回の打ち手が主因への対処になっていないと申し上げたのはこの意味です。

### モバイルとPCで差が出ている場合の見方

モバイルだけが極端に悪いなら、原因は次のどれかに絞れます。

| 疑い | 見分け方 |
|---|---|
| ファーストビューが重く、表示前に閉じられている | 表示速度を実測する。3秒を超えると離脱が跳ね上がる |
| ファーストビューの写真・見出しが刺さっていない | PCと同じ素材をモバイルに流用していないか確認する |
| 広告の訴求とLPの第一印象がずれている | 広告文とLP見出しを並べて読む。別のことを言っていたらここ |
| そもそも人が来ていない（計測ノイズ） | 関係者アクセス・ボットを除外した後の実数を見る |

### 計測ノイズの件

**関係者アクセスとボットが混入していました。** 数字を判断材料にする前に、これを除く必要があります。

- 社内・制作側のIPを除外する（GA4 の内部トラフィック除外。todo #313 として別途進行中）
- ボット除外を有効にする

除外前の数字で意思決定すると、**効いていない施策を「効いた」と誤認します。**

## 2. 打ち手（優先順）

### 打ち手1: ファーストビューの写真を差し替える（最優先）

滞在10秒で閉じられている以上、**勝負はファーストビューだけ**で決まっています。ここを触らずに他をやっても数字は動きません。

補助金LPのファーストビュー写真差し替えは以前から継続課題に入っていましたが、**この分析で優先度が上がりました。**（8/1 議事録の継続未着手3件の1つ）

- モバイルで最初に見える範囲に、**何の会社で・誰の何を解決するか**が1秒で分かる状態を作る
- PC用の横長写真をそのまま縮小しない。モバイルは縦画面なので、同じ写真でも情報量が落ちる

### 打ち手2: 計測をきれいにする

打ち手1の効果を測るために、**先にノイズを除く**必要があります。順番が逆になると、写真を替えた効果が判定できません。

- 内部トラフィック除外の設定（#313）
- ボット除外の確認

### 打ち手3: 表示速度を実測する

ファーストビューの画像が重いと、差し替えても表示前に閉じられます。打ち手1と同時に見ます。

### 打ち手4: 広告文とLP見出しの一致を確認する

広告で言っていることとLPの第一印象がずれていると、開いた瞬間に「違うページに来た」と判断されます。並べて読むだけで分かります。
