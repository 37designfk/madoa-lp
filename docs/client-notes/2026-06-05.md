## 反省点・学び

- 出来事: 打ち合わせ中の画面共有で LP の dev サーバー URL がすぐ出てこず、「出てこない」を連発しながらポートを探し回った（4321は別プロジェクトのサーバーで、madoa-lp は4325だった）
- 原因: 複数プロジェクトの dev サーバーを同時起動しており、どのポートがどのプロジェクトか把握しないまま共有を始めた
- 影響: 菊池さんを待たせる時間が発生。前回の「ダッシュボードURL迷子」と同種のもたつきが2回連続
- 教訓: クライアント打ち合わせ前チェックリストに「dev サーバー起動 + URL をブラウザで開いて確認」を追加。納品物URLと同様、アジェンダ末尾に当日使うURL一覧を書いておく
- カテゴリ: tooling
- 重要度: medium

- 出来事: 羽田野が Meta のアクセストークンを Claude Code のチャット欄に貼った可能性があり、古田がその場で注意した
- 原因: トークン・シークレットの取り扱いルール（1Password 経由、平文貼り付け禁止）が羽田野に共有されていない
- 影響: トークン漏えいリスク。実際に貼られたかは未確認だが、期限切れで再発行が必要な状態
- 教訓: 羽田野向けにシークレット取り扱いの最低限ルールを共有する（トークンは op 経由・チャットに貼らない・再発行時は古田が同席）。再発行するトークンは 1Password 登録から始める
- カテゴリ: technical
- 重要度: high
